# ELYSIUM PUNKS: elysiumpunk.fun (local build, not deployed)

Static website for ELYSIUM PUNKS, a 9,999 piece pixel punk NFT collection on the
Elysium chain (Kinetiq L2 on Hyperliquid, gas token HYPE). Built as local files
only. Nothing here is deployed, no repo, no DNS changes.

## Structure

- `index.html`: one page site.
  - Header with nav (The Paradise, Types, Whitelist, FAQ), X placeholder link,
    and a Connect Wallet placeholder button.
  - Hero: giant headline "9,999 PUNKS MADE IT TO PARADISE." plus a scrolling
    marquee of punk faces (pauses on hover).
  - Stat strip: 9,999 punks, 3 types, 1,000 whitelist spots, reveal in 24H.
  - 01 / THE PARADISE: story and the street x paradise trait system.
  - 02 / THE TYPES: Mortal (about 70%), Blessed (about 27%), Saint (about 3%)
    cards with sample faces.
  - 03 / WHITELIST: the three step flow, links to `whitelist.html (CLOSED state since 2026-11-09 per Yusup: page shows 'Not open yet'. The demo form was removed entirely; rebuild it at opening time from the flow spec in this README, wired directly to the real storage endpoint)`.
  - 04 / FAQ: mint timing TBA, price ($3.50 public, free whitelist), reveal
    exactly 24 hours after mint, secondary market on OpenSea, chain and gas.
  - Footer with the "Not affiliated with CryptoPunks" line.
  - Mint button is an inert "Mint opens soon" state. No fake mint is wired.
- `whitelist.html (CLOSED state since 2026-11-09 per Yusup: page shows 'Not open yet'. The demo form was removed entirely; rebuild it at opening time from the flow spec in this README, wired directly to the real storage endpoint)`: the whitelist registration form (client side only).
  - Validates EVM address format (0x + 40 hex), X username format, all three
    task checkboxes, and a random math captcha (regenerates on demand and
    after a failed submit).
  - Honeypot hidden field ("website") silently rejects bot submissions.
  - On success, derives a confirmation code from the address hash
    (format ELY-XXXXXX-XXXX) and shows a success state.
  - Submissions are stored in `localStorage` under the key
    `elysiumpunk_whitelist` as a demo store only.
- `style.css`: shared styles. Cream/gold/ink/red identity, Archivo Black
  display, Silkscreen pixel accents, Space Grotesk body, mobile-first.
- `img/`: 20 sample punk faces generated by
  `~/workspace/elysiumpunk-build/generator.py` (seeds 1 to 8, 11 to 18,
  700 to 702, 970).
